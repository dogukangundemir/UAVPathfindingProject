This project implements a geofence-aware path planning system for urban small Unmanned Aerial Vehicles (UAVs), building on the paper "Airspace Geofencing and Flight Planning for Low-Altitude, Urban, Small Unmanned Aircraft Systems". Developed in MATLAB, it integrates 3D geofencing (keep-in/keep-out zones around buildings), Q-learning-based reinforcement learning (RL), and 2D/3D pathfinding to optimize UAV trajectories in dynamic urban environments. The system processes OpenStreetMap (OSM) data to model obstacles and roads, enabling realistic simulations of UAV navigation through Manhattan-like cityscapes. The RL module trains agents to avoid geofences using penalty-driven rewards, while dynamically adapting to introduced hazards like mid-mission danger zones. Algorithms include visibility graph-based path planning, intersection checks for 3D geofences, and interactive waypoint customization. Visualizations such as animated GIFs and 3D plots demonstrate path evolution during training and final optimal routes. Designed for urban drone operations, this implementation bridges computational geometry with adaptive learning, offering a scalable framework for safe UAV traffic management in complex airspace.
