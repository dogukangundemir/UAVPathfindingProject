This project implements a geofence-aware path planning system for urban small Unmanned Aerial Vehicles (UAVs), building on the paper "Airspace Geofencing and Flight Planning for Low-Altitude, Urban, Small Unmanned Aircraft Systems". Developed in MATLAB, it integrates 3D geofencing (keep-in/keep-out zones around buildings), Q-learning-based reinforcement learning (RL), and 2D/3D pathfinding using Dijkstra’s algorithm and A* for optimized trajectory generation in dynamic urban environments. The system processes OpenStreetMap (OSM) data to model obstacles and roads, enabling realistic simulations of UAV navigation through Manhattan-like cityscapes. Dijkstra’s algorithm ensures shortest-path computation in visibility graphs for static obstacle avoidance, while A* enhances efficiency with heuristic-guided search in grid-based environments. The RL module trains agents to dynamically adapt to geofences and mid-mission hazards using penalty-driven rewards, complementing traditional pathfinding methods. Algorithms include 3D intersection checks, visibility graph construction, and interactive waypoint customization. Visualizations such as animated GIFs and 3D plots demonstrate path evolution during training and final optimal routes. Bridging classical graph-based algorithms (Dijkstra, A*) with adaptive learning, this framework offers a hybrid approach for scalable, safe UAV traffic management in complex urban airspace.
